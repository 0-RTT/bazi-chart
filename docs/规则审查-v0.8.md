# 排盘规则审查（v0.8.0）

这份文档回答一个问题：**屏上每一个字，凭什么这么排。**

审查覆盖从「输入一个时刻」到「神煞落在哪一柱」的全部环节，共 14 组规则、
38 种神煞。每条都标出古籍出处与实现位置；凡有流派分歧的，写明本应用取了哪一支、
为什么取这一支。凡本版改动的，写清改动前后的差别与判定依据。

校验由两部分组成，都不依赖人工比对：

- `tools/verify/*.py`（8 个脚本，952 项断言）——用 Python 独立实现一遍表格与算法，
  与 Kotlin 侧逐项对撞。这部分不需要 JDK，CI 第一道关卡就跑它。
- `core/*/src/test`（5 个测试类）——Kotlin 侧回归，含 5 张构造盘的逐柱**集合相等**。

> 所有命例都是构造盘（合法干支组合），不是任何真人的出生数据。

## 一、时间的归一：最大的错误来源

排盘错，九成错在这里，不在四柱公式。

| 环节 | 处理 | 依据 |
| --- | --- | --- |
| 农历输入 | 先换公历钟表时，再做真太阳时校正 | 顺序不能反：校正作用于时刻，不作用于月日 |
| 经度差 | 每偏离 120°E 一度折 4 分钟 | 地球自转 15°/小时 |
| 均时差 | NOAA 近似式，逐日取值，幅度 ±16 分 | 轨道偏心率 + 黄赤交角，精度约 ±10 秒 |
| 夏令时 | 不自动推断，由用户显式填 0 或 −60 分 | 1986–1991 年中国夏令时区间边界易错，宁可少猜 |
| 23:00–23:59 | 默认按通行子平法算**次日**日柱（晚子时） | 可切「早子时」派；`SectConfig.ziHour` |

**默认不启真太阳时。** 校正是对的，但它会把钟表时推离整点：07:00 生于 116.4°E，
校正后 06:40，时柱从辰时退回卯时。通行排盘工具默认按钟表时定时辰，本应用与之一致，
需要校正的人在录入页显式打开。这一条是 v0.7.0 修的，当时的症状是「时柱错一个时辰」。

## 二、四柱

| 柱 | 规则 | 出处 |
| --- | --- | --- |
| 年柱 | 以**立春**换年，非正月初一、非元旦 | 《渊海子平》「正月建寅」 |
| 月柱 | 十二**节**换月（立春、惊蛰、清明…小寒）；月干用五虎遁 | 《三命通会·论月建》 |
| 日柱 | 连续六十甲子，子时归日见上表 | — |
| 时柱 | 时支两小时一辰，时干用五鼠遁（甲己还加甲…） | 《渊海子平》 |

`core/bazi/BaziCalculator.kt`（五虎遁用于流月，见第六条）。

## 四、十神

判据是二维的：**五行生克关系 × 阴阳同异**。同为偏，异为正。

| 关系 | 同阴阳 | 异阴阳 |
| --- | --- | --- |
| 同我 | 比肩 | 劫财 |
| 我生 | 食神 | 伤官 |
| 我克 | 偏财 | 正财 |
| 克我 | 七杀 | 正官 |
| 生我 | 偏印 | 正印 |

命盘表两行：**主星**（天干对日主，日柱即「元男/元女」）、**副星**（藏干对日主，本气深色、
中气余气淡色）。v0.5.0 起与界面用词统一，「十神」改称「主星/副星」，与通行排盘一致。

实现：`core/bazi/GanZhi.kt` 的 `TenGod.between`；校验：`verify_plate.py` 独立实现后逐格对撞。

## 五、十二长生（星运 / 自坐）

阳干顺行、阴干逆行；起点为各干长生之地：

甲亥、乙午、丙寅、丁酉、戊寅、己酉、庚巳、辛子、壬申、癸卯。

两行的区别容易混，界面上并列给出：

- **星运**：日主落在各柱地支的十二长生。四柱共用一个基准，故日柱的星运必然等于日柱的自坐。
- **自坐**：本柱天干坐本柱地支。丁坐酉为长生、丙坐午为帝旺，与日主是谁无关。

实现：`GrowthPhaseTable.of(gan, zhi)`；校验：`verify_plate.py` 以构造盘一逐柱核对
（丁酉长生、甲申绝、丙午帝旺、壬寅病）。

## 六、空亡（旬空）

十天干配十二支，每旬多出两支即空亡。**命盘表「空亡」行给的是每一柱自身干支所属旬的空亡**，
四柱通常各不相同；「落空」另算，指该柱地支是否落在**日柱**旬空之内。两者语义不同，不可合并
（盘面文本里也分列 `空亡` 与 `落空` 两行）。

校验：`voidBranches()` 以同余式求解，`verify_plate.py` 对六十甲子逐一断言「空支恒两支、
且不含本柱地支」。

## 八、大运与起运

| 项 | 规则 |
| --- | --- |
| 方向 | 阳男阴女顺排，阴男阳女逆排（以年干阴阳与性别定） |
| 起点 | 月柱的下一柱（顺）或上一柱（逆） |

## 九、流年与流月

- 流年干支：`(公历年 − 4) mod 60`，以立春为界。虚岁 = 年 − 出生年 + 1。
- 流月：十二节为界，寅月自立春起；月干用五虎遁，年干取该干支年的年干。
  丑月终于次年立春，属正常跨年，不是越界。

校验：`verify_prompt.py` 以五虎遁口诀逐月核对月干，并断言「丑月终点 = 次年立春」。

## 十、胎元、胎息、命宫、身宫

| 项 | 取法 |
| --- | --- |
| 胎元 | 月干进一位、月支进三位（己巳月 → 庚申） |
| 胎息 | 日干进五位、日支取合（甲申日 → 己巳） |
| 命宫 | 以中气定月、月时相配，十四/廿六减之；天干用五虎遁 |
| 身宫 | 月支与时支相加取中，天干同法 |

四项由 tyme4kt 的 `EightChar` 提供。命宫流派最杂，此处取的是通行排盘工具（含问真）
一致的那一支：巳月申时、甲申年 → 命宫**戊辰**、身宫**丙寅**，本应用与之一致。

> 命宫另有「以农历月起子逆数」等几种算法，结果不同。本应用不提供切换——
> 切换项越多，越容易出现「同一张盘在两台机器上不同」的问题。若要换支，
> 改 `CalendarConverter` 一处即可。

## 十二、神煞（38 种）

神煞是所有环节里分歧最大的一段。本应用的取舍原则是：**能落到口诀的就收，
只能落到「某本书某页有一张表」的不收**。查法基准写得越含糊，不同工具排出来差得越远。

### 12.4 年支系（三会方，不是三合局）

孤辰、寡宿按**三会方**分组：亥子丑、寅卯辰、巳午未、申酉戌。
这一组最容易抄错——寅既在寅午戌（三合）又在寅卯辰（三会），孤辰寡宿取后者。
若套三合索引，卯年会被算成「寡宿戌」，实测没有。

| 神煞 | 查法 |
| --- | --- |
| 孤辰 | 亥子丑见寅、寅卯辰见巳、巳午未见申、申酉戌见亥 |
| 寡宿 | 亥子丑见戌、寅卯辰见丑、巳午未见辰、申酉戌见未 |
| 红鸾 | 子卯、丑寅、寅丑、卯子、辰亥、巳戌、午酉、未申、申未、酉午、戌巳、亥辰 |
| 天喜 | 红鸾之对冲（子酉、丑申…亥戌）。**只以年支查** |
| 丧门 | 年支顺行二位 |
| 勾绞煞 | 年支前三位、后三位 |

### 12.5 三合局四煞 + 将星

桃花、驿马、华盖、亡神、劫煞、将星，全部由三合局分组查表：

| 局 | 桃花 | 驿马 | 华盖 | 亡神 | 劫煞 | 将星 |
| --- | --- | --- | --- | --- | --- | --- |
| 申子辰 | 酉 | 寅 | 辰 | 亥 | 巳 | 子 |
| 寅午戌 | 卯 | 申 | 戌 | 巳 | 亥 | 午 |
| 巳酉丑 | 午 | 亥 | 丑 | 申 | 寅 | 酉 |
| 亥卯未 | 子 | 巳 | 未 | 寅 | 申 | 卯 |

**查法基准：年支与日支并查。** 年支与日支常分属两个三合局，只取年支会漏掉日支所主的那组。

**华盖与将星都要排除基准宫位。** 四库之支属本局时华盖正是它自己（亥卯未见未、申子辰见辰），
三合中神（子午卯酉）也常在本命某一柱上；不排除则「年支取年支」恒中，噪声大于信息。
这是 v0.6.0 把将星整条删掉的原因，v0.8.0 改为「排除基准宫位后保留」：

- 构造盘一（丁酉 甲申 丙午 壬寅）：年支酉、日支午皆为中神，排除后本盘无将星。
- 己卯 甲戌 乙亥 丙子：日支亥属亥卯未、将星为卯，正落**年支**，此处年柱不是基准宫位，故成立。

### 12.7 年纳音系：学堂、词馆

《三命通会·论学堂词馆》：金命见巳、木命见亥、水命见申、火命见寅、土命见申为学堂；
金命见申、木命见寅、水命见亥、火命见巳、土命见亥为词馆。土寄水宫，故与水土同。

实际取的是**年柱纳音五行**的长生与临官。对照：年柱纳音泉中水（水长生在申）而命中见申，
通行工具即标「学堂」于该柱。

### 12.8 童子煞：纳音法与季节法并查

- 纳音法：金木命见午卯、水火命见酉戌、土命见辰巳。
- 季节法：春秋（寅卯辰申酉戌月）见寅子，冬夏见卯未辰。

两法并用才对：只走纳音会漏掉日支上的童子煞，只走季节会漏掉纳音所主的那一支。

### 12.9 刻意不收的

| 神煞 | 为什么不收 |
| --- | --- |
| 血刃 | 查法在几种「神煞大全」之间互相矛盾（有作羊刃别名、有作三合旺神、有作月支顺行者），落不到统一口诀 |
| 披麻 | 同上，且各家给的宫位不一致 |
| 天罗地网 | 「戌亥为天罗、辰巳为地网」只给了集合，没给「以哪一柱为准」 |
| 金锁铁蛇、六厄、灾煞 | 同属表源不明，收了只会与通行工具打架 |

判断标准很简单：**同一条查法在两种排盘工具上排出不同结果，而我又找不到口诀判谁对，
就不收。** 少一项不会让人读错盘，多一项错的会。
